# 0.3.26：操作确认与折叠查询交互修正

- 加固主界面开始操作和停止任务的确认窗口：页面、前后台状态或当前操作状态变化后，旧窗口的确认不再提交操作；确认只消费一次，重复点击不能重复提交。原有登录、权限、任务日志、设备操作和受控提交规则保持不变。
- SPEC 对比页中，手动 Model→URN 查询进行时即使折叠查询区域，也保留简短状态和可见的取消入口。折叠本身不会自动取消或再次请求；用户仍可明确取消，再继续本地 JSON 对比。原有选择绑定、过期回调隔离和独立工作线程规则不变，不新增公共 SPEC JSON 自动获取。
- 保留已发布的手动固件包资料查询、报告用例标题选择、报告筛选、PDID 产品查询、脱敏说明本地检索、公告、设备调试、OTA 和 BL616 SerialLab 功能；没有新增功能按钮，也不宣称 Windows 工具完整功能等价。

验证范围：最终源码的新完整主机验证通过 20 个规范阶段、13 个外层阶段和 7 项显式守卫；Python 源码测试 344 项、发布测试 88 项，另有 2441 个数据验收负例检查。完整主界面合成确认测试 156 项、SDK-free 固件隐私测试 230 项（保留旧 44 项）、Model 查询界面测试 274 项，以及原有监听器和各专项门禁通过；完整监听器的 15 份实际原始输出归属已核对。生产输入仍为 122 个 Java 源文件、129 项编译输入。这些是不同层级的执行计数，不能相加当作去重后的覆盖总数；主机合成测试和构建通过不等同于手机或硬件验收。

失败记录保留：本版首次本地数据审计的最终验收器未正确拦截目录日志附加内容的负例，因此当次审计未获封存验收；仅修正本地审计器的精确日志绑定，未修改产品、主机验证或附件，也未重跑主机任务。随后对同一实际附件重新完成全部三条数据审计命令，才建立本次数据验收。原失败快照和修正前后的审计代码仍保留。本版此前 25 项选定 Python 测试和局部检查的通过只是局部证据，完整验收来自其后的新完整主机验证。

历史上的 0.3.25 本地固件界面与源码解析超时、未复现的单独诊断、首次完整主机验证的引号写法测试误报及仅改测试判定的恢复记录均未被改写为通过；0.3.23 工作线程超时和 0.3.24 历史失败也未被宣称已修复。本版交互修正不证明这些历史超时根因已经解决。

APK 已通过原证书 v2/v3 签名核验，非签名应用内容与已验未签名构建逐成员一致。公开下载附件仅为 APK、更新清单和校验和；签名与字节一致性不代表安装或原地升级已经验证。

仍未验收：Android 手机安装、原地升级、原生界面与生命周期、权限弹窗、真实账户与云端接口兼容性，以及实际 Wi-Fi/TCP、BLE/GATT、UART、无线链路和 BL616 板卡行为。target-time／target-temperature 的确切脱敏平台定义仍缺失，既有实际读取问题和 UNKNOWN 诊断不能据此宣布解决或放宽规则。

BL616 SerialLab r3 固件仍是独立外部配套，本次 APK 不包含或自动刷写该固件。真实接线、电平、报文模拟和串联桥接须单独验证；不能把手机断开等同于硬件安全停止，也没有掉电自动旁路保证。
