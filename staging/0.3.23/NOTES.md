# 0.3.23：手动 PDID 产品查询与报告说明本地检索

- 新增手动输入 PDID 的平台产品查询入口。只读查询不从 MiBeacon 广播推断设备身份，不写回设备，也不自动轮询或重试。
- 新增报告条目说明的本地检索：检索已显示、脱敏后的说明文字，保留原始报告行和总数；检索本身不发起新云端请求，也不复制或导出内容。
- 保留既有平台公告、设备调试、OTA、云端功能、离线 SPEC 对比与 BL616 SerialLab 功能。本次不新增设备控制或固件功能，也不宣称与 Windows 工具完全等价。

验证范围：完整 20 阶段主机离线验证、7 项发布守卫和 SerialLab 六组回归已通过；PDID 专项包含 432 项检查，本地检索新增 2129 项检查，原有报告回归仍保留。生产输入为 109 个 Java 源文件、116 项编译输入。专项可能被不同验证链重复调用，计数不是去重后的总测试数。以上是主机合成、编译与构建证据，不是手机或硬件验收。

曾出现一次本地主机工作线程等待超时；后续定点回归和独立完整主机验证通过，但原始超时根因仍未确定，不据此宣称该问题已修复。

APK 已通过原证书 v2/v3 签名核验，非签名应用内容与已验未签名构建逐成员一致。公开下载附件仅为 APK、更新清单和校验和；签名与字节一致性不代表安装或原地升级已经验证。

仍未验收：Android 手机安装、原地升级、原生界面与生命周期、权限弹窗、真实账户与云端接口兼容性，以及实际 Wi-Fi/TCP、BLE/GATT、UART、无线链路和 BL616 板卡行为。既有 target-time／target-temperature 实际读取问题未据此确认解决。

BL616 SerialLab r3 固件仍是独立外部配套，本次 APK 不包含或自动刷写该固件。真实接线、电平、报文模拟和串联桥接须单独验证；不能把手机断开等同于硬件安全停止，也没有掉电自动旁路保证。
