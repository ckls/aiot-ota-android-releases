# 0.3.27：B8G R0.8 板型适配与接线引导

- BL616 SerialLab 按固件报告的板型和完整能力开放操作。R0.8 支持监听、两线/四线单侧模拟；旧 MHCWB8G 测试板保留四线软件桥接。未知或损坏的能力报告禁止主动输出。
- 新增七种接法引导，区分人工接线确认与 GPIO 配置 ACK。连接变化、错误确认、UART 故障及停止路径保留失效和发送限制，不自动恢复模拟。
- R0.8 有源硬件转发依赖供电和正确跳帽，不是掉电旁路。J5 外供只为调试板供电；模拟 Power 时，控制板可能需要独立供电支路并共地。
