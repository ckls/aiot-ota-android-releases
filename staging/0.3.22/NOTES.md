# 0.3.22：平台公告只读查看

- 新增手动打开的平台公告列表与详情入口，展示平台返回的未读、重要标记；查看详情不会自动标记已读，也不发送已读状态更新。
- 公告正文按安全纯文本展示，不执行正文内容或自动跳转链接；采用有界读取、旧请求结果隔离与敏感内容保护，不自动轮询或重试。
- 保留既有设备调试、OTA、云端功能、离线 SPEC 对比和 BL616 SerialLab 功能。本次新增的是公告查看，不是新的设备控制或固件功能。

验证范围：完整 20 阶段主机离线验证、7 项发布守卫和 SerialLab 六组回归已通过；公告专项共 392 项检查，SerialLab 共 3453 项断言。生产输入为 104 个 Java 源文件、111 项编译输入。以上是主机合成、编译与构建证据，不是手机或硬件验收。

APK 已通过原证书 v2/v3 签名核验，非签名应用内容与已验未签名构建逐成员一致。公开下载附件仅为 APK、更新清单和校验和；签名与字节一致性不代表安装或原地升级已经验证。

仍未验收：Android 手机安装、原地升级、原生界面与生命周期、权限弹窗、真实账户与云端接口兼容性，以及实际 Wi-Fi/TCP、BLE/GATT、UART、无线链路和 BL616 板卡行为。既有 target-time／target-temperature 实际读取问题未据此确认解决。

BL616 SerialLab r3 固件仍是独立外部配套，本次 APK 不包含或自动刷写该固件。真实接线、电平、报文模拟和串联桥接须单独验证；不能把手机断开等同于硬件安全停止，也没有掉电自动旁路保证。
