0.3.4：新增 SPEC 云端单属性缓存读取。

- 刷包页新增“SPEC 云端缓存读取”。先验证平台账号，再手动读取环境、设备和 SPEC 定义，选择可读属性后读取云端缓存。
- 支持合法的 0、false、空字符串及精确大整数显示。缓存更新时间未知；显示的本机接收时间不代表设备采样时间。
- 固定只读请求与 datasource=1；没有轮询、批量读取、属性写入、动作调用或设备实时读取回退。
- 账号/会话变化、切换选项、页面离开和销毁都会使旧结果失效。选择窗口增加身份及代次校验，阻止已关闭窗口的迟到回调修改新选择。
- 保留任务搜索、完整固件列表、状态/时间显示和日志阅读修复。

验证范围：
- 独立代码审查、完整离线回归、SDK35构建及原签名核验通过。
- 官方 Android26 Google APIs 模拟器中，原样读取Activity等生产文件与真实Android CookieManager通过224项合成界面检查；29次请求均由内存测试响应处理，没有真实小米请求。
- 主机选择器专项回归203项及独立72项检查通过。真实账号权限、服务端完整响应、缓存时效、完整登录链路及实体设备效果仍未验收。
- 0.3.3已验证普通包管理器覆盖升级及未登录首页/关于页。本版新增功能的模拟测试不等同本版正式APK安装或应用内升级流程验收；应用内联网下载/安装的完整成功路径仍待验证。
