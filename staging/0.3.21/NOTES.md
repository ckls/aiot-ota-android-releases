# 0.3.21：BL616 串口调试与诊断

- 新增独立 BL616 串口调试入口，支持 Wi-Fi/TCP 与 BLE 连接、协议报文观察、原始值与工程值解析，以及受限制的报文模拟。协议观察兼容不等于允许发送；未知方向不会被当作有效反馈或发送方向。
- 保留连接状态、权限、重复操作、旧会话回调、发送超时与停止控制。两线/四线接线设置以设备确认结果为准；两线方案不开放串联桥接，断线或重连不会自动恢复主动发送。
- 同时包含 0.3.20 的原始、未修改 READ_PROP 用例单次云端启动功能：提交前明确确认目标并关闭 AI 分析，先保存本机防重标记；不确定结果不会自动重试。返回任务编号不代表执行成功，也不保证服务端或设备没有其他影响。
- 保留既有 OTA、设备调试、云端功能进度/历史、离线 SPEC 对比，以及敏感内容保护。

验证范围：完整 20 阶段主机离线验证及 7 项发布守卫已通过；SerialLab 独立六组主机回归共 3453 项断言通过。生产输入为 99 个 Java 源文件、106 项编译输入。以上均为主机合成或编译验证，不是手机、射频、串口或硬件验收。

APK 已通过原证书 v2/v3 签名核验，应用内容与已验未签名构建逐成员一致。公开下载附件仅为 APK、更新清单和校验和；签名与字节一致性不代表安装或原地升级已验证。

仍未验收：Android 手机安装、原地升级、原生界面与生命周期、权限弹窗、实际 Wi-Fi/TCP、BLE/GATT、UART 通信及 BL616 硬件行为；真实云端账户和设备执行兼容性也未据此验证。target-time／target-temperature 的实际读取故障仍未确认解决。

BL616 SerialLab r3 固件是独立外部配套，本次 APK 不包含或自动刷写该固件；固件烧录、接线、电平转换、切换与物理安全须单独验收。报文模拟和串联桥接可能影响设备行为；不能把手机断开等同于硬件安全停止，串联桥接也没有掉电自动旁路保证。
