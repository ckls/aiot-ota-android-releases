# 0.3.28：GPIO、受保护 PWM 与波形采集

- BL616 调试板新增 GPIO、四路共频 PWM、单路 ADC 和八路逻辑采集；支持波形缩放、游标及 CSV 导出。
- PWM 要求有效 guard v1：启用前取得只读量化方案，由 Android 独立核算并以 plan_id 绑定启用；启用及续约确认必须与方案一致。能力频率范围须落在合同 10–100000 Hz 内。
- 不支持或报告损坏的 PWM guard 仅禁止 PWM，不伪造固件能力；GPIO、ADC、逻辑采集按有效能力保留。输出采用有限租约，普通心跳不续约，离页、后台、断线或停止后不自动恢复。
- 保留原证书、OTA、设备调试、功能测试及升级控制。

验证范围：最终候选在本地 JDK21/SDK35 完成20阶段离线套件；SerialLab六组3801次断言，显式重放r6的六组PWM轨迹与六份ADC/逻辑采集数据。各层计数不相加为去重覆盖总数。首批聚合因选择了不匹配的现有JSON测试依赖失败，保留失败记录；使用合同规定依赖后完整通过，不降低门槛。

原有受控 JDK17 签名流程另行通过完整离线、六组 SerialLab 与签名发布门禁；该流程未传入跨端样本参数，跨端样本覆盖来自上述本地独立批次，不能混为同一批测试。

独立隔离审计使用固定产品源码和 JDK17/SDK35 构建未签名对照包，核验原证书及 v2/v3，7个应用ZIP成员与正式签名包逐字节一致；版本0.3.28/code32、minSDK26及targetSDK35正确。该审计成功，未重新签名。

未验收：手机安装与原地升级、Android界面/生命周期/权限弹窗，真实账号/云端兼容性、Wi-Fi/BLE/GATT、UART/板卡、物理波形与启停瞬态、ADC校准/采样时序及逻辑抖动/漏采。软件预检不能证明真实硬件故障时绝无短暂输出。
