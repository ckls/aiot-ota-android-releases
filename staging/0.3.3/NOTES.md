0.3.3：修正固件状态和上传时间显示，新增云端任务搜索。

- “全部平台版本”按开发者平台的 isLatest/statusDesc 显示状态，上传时间转换为手机本地日期；未知、缺失或不可信数值明确标示，不再一律显示“其他状态”。
- “任务选项 → 搜索云端任务”支持关键词搜索、清除条件与刷新。每次最多20条匹配结果，不代表完整任务历史；输入文字本身不会请求云端。
- 保留0.3.2的完整固件分页、原始数字精度防护及独立日志阅读器。搜索结果按账号、会话和请求代次隔离，迟到结果不会覆盖新查询。
- 目录显示修正不改变固件选择、OTA权限或刷写逻辑，不增加自动轮询，不自动重试OTA。

验证范围：
- 完整离线回归、独立代码复核、SDK35构建与原签名核验通过。
- API26软件模拟器中，显示辅助类133项原生JSON检查通过；任务搜索58项检查、12个场景通过，覆盖原生输入/键盘、重复搜索、清除、日志阅读器与迟到回调。
- 搜索测试使用复用生产方法的独立合成Activity及模拟接口，显示测试是辅助类验证；这些结果不等于完整生产应用、真实小米账号搜索、实体手机或应用内安装器已验收。
- 云端设备属性读取仍在独立开发测试，本版尚未包含。

沿用原签名，versionCode从6增至7。0.3.1/0.3.2可在“关于 → APP在线更新”检查更新，也可手动覆盖安装；不要卸载旧版，以免丢失本机资料。
