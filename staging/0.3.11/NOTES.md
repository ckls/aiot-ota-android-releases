# 0.3.11 登录兼容性修复

- 修复测试平台登录交换被通用 JSON 校验提前拒绝的问题。按原 Windows 契约，登录交换读取新会话 Cookie，不再要求成功响应正文必须是 JSON。
- 保留业务错误拒绝、有效账号资料校验、新会话唯一性及 Cookie 保存确认，避免旧会话或失败响应被误当作登录成功。
- 版本号 0.3.11，版本代码 15。

## 已验证范围

完整 JDK 17 / Android SDK 35 离线构建与 19 阶段测试通过。新增 477 项登录合成检查零失败、零真实网络请求；10 项登录页面源码检查通过。实际未签名 APK 已完成独立源码与内容核验。发布 APK 使用原签名证书；v2/v3 签名已独立核验，生产内容与已验收的离线构建逐字节一致。

## 尚未验证

尚未验证真实测试平台账号登录、Android 运行时、安装升级、真实设备或真实云端业务。用户所遇失败响应的实际正文与状态码尚未采集。此版本依据已核对的接口契约修复，不将合成测试结果当作真实登录成功证明。
