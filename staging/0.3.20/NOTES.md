# 0.3.20：确认后单次启动原始 READ_PROP 用例

- 新增原始、未修改 READ_PROP 测试用例的单次云端启动入口，严格绑定定义、账户、环境、设备与目标，并在提交前显示目标确认。仅允许明确关闭 AI 分析，不开放 AI 开启或其他用例类型。
- 提交前先保存本机全局防重标记；遇到不确定结果不会自动重试或轮询。只有用户再次明确确认重复提交风险，才允许单次手动覆盖。该标记不是服务端幂等保证，也不能跨设备或应用数据清除防重；返回任务 ID 不代表测试已成功执行。
- 保留普通诊断页截图、敏感字段受保护私密显示，以及本机 SPEC 结构对比和原始定义保护。未增加应用权限，也未加入定义回云保存。

完整 20 阶段离线验证及 7 项发布守卫已通过，包含 6 个全源 SDK 编译阶段、91 个 Java 源文件及 95 项生产输入。CI 使用既有固定摘要的官方 JSON 依赖离线副本，没有新增依赖下载；CI 专用依赖与验证文件不进入产品树或 APK。

实际 APK 已独立核验原证书 v2/v3 签名，全部应用内容与已验未签名包逐成员一致。公开附件仅 APK、更新清单和校验和。

本次开发与验证未提交真实云端或设备测试。READ_PROP 是请求类型，不保证服务端或设备没有其他影响；真实账户、接口结构与平台执行兼容性尚未验证。Android 原生窗口、截图、最近任务预览、布局、生命周期和安装升级仍未验收。target-time／target-temperature 的实际读取故障仍未确认解决。
