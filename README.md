# OTA 测试助手 Android 下载

本仓库公开 APK、版本说明、更新清单和 SHA-256 校验文件。应用源码与签名密钥保存在私有源码仓库。

## 下载与安装

请在 [正式 Releases](https://github.com/ckls/aiot-ota-android-releases/releases/latest) 下载 APK。0.3.0 尚无应用内更新入口，首次升级至 0.3.1 请下载后覆盖安装。后续版本可以通过应用内的更新入口检查并下载，由 Android 系统确认安装。

覆盖安装沿用原签名。应用内更新会验证下载大小、SHA-256、包名、递增版本号和原签名。不要为升级先卸载应用，以免丢失手机上的账号资料。

0.3.1 已完成离线回归、原签名核验和 Android 35 编译；安装器、权限及真实平台完整版本响应尚未实机验收。具体状态见各版本说明。

## 发布流程

经过审查的签名 APK、`update-manifest.json`、`SHA256SUMS` 和公开 `NOTES.md` 放入 `staging/<版本>/`。受信任维护者在主分支执行 **Publish verified APK**：

1. 检查 APK 包名、版本、签名和本地清单。
2. 固定版本标签，建立草稿，只上传三个发布附件。
3. 核对服务端摘要并重新下载，逐字节回验。
4. 勾选 `publish` 后才正式发布为最新版本，并再次回验。

相同提交、相同说明和相同附件的草稿可以继续发布；已有正式版本或不一致的草稿会停止。不会替换已有附件，也不会覆盖正式发布。

工作流使用 GitHub 为本仓库提供的临时令牌。公开仓库不读取签名密码、私钥、平台账号或私有源码。
